# LLMGE-Assisted Stock Portfolio Optimization

This repository details a project that uses the LLMGE (Large Language
Model Genetic Evolution) framework together with the FinRL library to
automatically optimize Deep Reinforcement Learning (DRL) algorithms for
stock portfolio weight allocation.

The primary objective is to maximize investment returns while
maintaining a competitive risk profile by determining the optimal
weights (the percentage of capital to allocate to each stock).

## Core Concept: Evolving Trading Algorithms

Instead of training a fixed DRL algorithm, this project applies an
evolutionary process to automatically generate and evaluate
modifications to the algorithm's Python source code.

## 1. Problem: Stock Portfolio Optimization

We treat portfolio allocation as a continuous control problem:

-   At each time step, the agent outputs a set of weights.
-   Weights must sum to 1.0.
-   Each weight represents the capital allocation for a specific stock.

## 2. Tools: FinRL and DRL

### FinRL Framework

-   Provides a standardized, Gym-compatible environment for financial
    simulations.
-   Handles market data ingestion, technical indicators, and environment
    setup.

### DRL Agents

-   Actor--Critic methods are used to learn optimal weight allocation
    policies.
-   Agents improve performance by interacting with the simulated trading
    environment.

## 3. Engine: LLMGE (Genetic Evolution)

LLMGE evolves the DRL model code itself:

-   Takes a DRL algorithm (such as DDPG) as seed code.
-   Applies genetic operations (mutation, crossover) to selected code
    blocks.
-   Backtesting performance determines evolutionary fitness.

## System Architecture

### 1. Market Environment Layer

-   Uses an OpenAI Gym-compatible MDP setup.
-   Incorporates market data such as price history, log-returns,
    technical indicators, and Huber features.
-   Focuses solely on portfolio weight allocation.

### 2. DRL Agent Layer

-   A custom DRLAgent wrapper integrates with evolved models.
-   Replaces standard SB3 models with LLMGE-generated variants.
-   Outputs weight vectors (e.g., `[0.20, 0.40, 0.40]`).

### 3. LLMGE Pipeline

-   Seed algorithm lives in `model.py`.
-   Evolvable code regions are explicitly marked.
-   Evolution loop: generate mutated candidates, train them, backtest
    via `eval.py`, compute metrics, select survivors.

## Baseline DRL Algorithms

| Algorithm | Type                               | Description                                             |
| --------- | ---------------------------------- | ------------------------------------------------------- |
| DDPG      | Deep Deterministic Policy Gradient | Off-policy continuous-action Actor–Critic               |
| TD3       | Twin Delayed DDPG                  | Two critics, reduced Q-overestimation, more stability   |
| A2C       | Advantage Actor–Critic             | On-policy learning with advantage-based updates         |
| PPO       | Proximal Policy Optimization       | On-policy method using clipped loss for stable training |


## Workflow

### Data Preprocessing (`preprocess.py`)

-   Downloads raw market data.
-   Cleans and augments with technical indicators.
-   Generates close prices, log-returns, and Huber features.
-   Saves processed datasets as `.pkl` files.

### Model Definition (`model.py`)

-   Contains the seed algorithm used for evolution.
-   Includes specially marked evolvable blocks for LLMGE.

### Agent Instantiation (`utils/custom_DRLAgent.py`)

-   Wraps standard SB3 agents.
-   Loads the evolved models generated by LLMGE.

### Evaluation (`eval.py`)

-   Builds training and trading environments from `.pkl` files.
-   Trains the DRL agent.
-   Runs backtests.
-   Outputs annual return, volatility, and Sharpe ratio to
    `results.txt`.

## Local Setup

### Prerequisites

-   Python installed
-   Two virtual environments:
    -   Main LLMGE environment (root)
    -   FinRL environment: `.venv_finrl`

### Step 1: Clone the Repository

``` bash
git clone <repository-url>
cd <repository-name>/sota/FinRL
```

### Step 2: Set Up Virtual Environments

Create the main LLMGE environment at the root and the FinRL environment
inside `sota/FinRL`.

### Step 3: Data Preprocessing

``` bash
python preprocess.py
```

### Step 4: Run Baseline Evaluation

``` bash
python eval.py
```

### Step 5: Start LLMGE Evolution

After `seed_results.txt` is generated, integrate FinRL with the LLMGE
pipeline to begin evolving `model.py`.

## Important Note on Data Paths

Ensure that:

-   The output paths of `preprocess.py`
-   Match the input paths expected by `eval.py`

Otherwise evaluation may fail or load incorrect data.
